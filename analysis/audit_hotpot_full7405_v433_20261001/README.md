# 本目录代码说明

本目录属于历史实验的一个版本。不要与其他目录同名模块混用。

| 文件 | 具体作用 | 详情 |
|---|---|---|
| [audit_results.py](<audit_results.py>) | 对审计执行完整性、协议、评分、成本或可复现性检查；可能生成派生报告，不应直接视为新实验结果。 | [F0095](<../../docs/files/F0095.md>) |
| [plot_results.py](<plot_results.py>) | 将已有统计结果制作成plot_results.py图表/表格/展示文件；不负责产生新的模型答案。 | [F0096](<../../docs/files/F0096.md>) |
