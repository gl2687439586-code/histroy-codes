# 本目录代码说明

本目录属于历史实验的一个版本。不要与其他目录同名模块混用。

| 文件 | 具体作用 | 详情 |
|---|---|---|
| [analyze.py](<analyze.py>) | 在所属实验数据上计算/复核analyze.py，输出派生统计或诊断；若用于选策略，应检查题目隔离与未来信息边界。 | [F0118](<../../../docs/files/F0118.md>) |
| [audit_balanced_prefix.py](<audit_balanced_prefix.py>) | 对审计执行完整性、协议、评分、成本或可复现性检查；可能生成派生报告，不应直接视为新实验结果。 | [F0119](<../../../docs/files/F0119.md>) |
| [audit_evidence_windows.py](<audit_evidence_windows.py>) | 联合审计相邻预算答案翻转与完整可见支持句的新增/丢失。 | [F0120](<../../../docs/files/F0120.md>) |
| [audit_repeat_exposure.py](<audit_repeat_exposure.py>) | 对审计、重复执行执行完整性、协议、评分、成本或可复现性检查；可能生成派生报告，不应直接视为新实验结果。 | [F0121](<../../../docs/files/F0121.md>) |
| [audit_type_plan.py](<audit_type_plan.py>) | 对审计执行完整性、协议、评分、成本或可复现性检查；可能生成派生报告，不应直接视为新实验结果。 | [F0122](<../../../docs/files/F0122.md>) |
