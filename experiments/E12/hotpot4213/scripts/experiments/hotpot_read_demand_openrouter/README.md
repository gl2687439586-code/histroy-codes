# 本目录代码说明

本目录属于历史实验的一个版本。不要与其他目录同名模块混用。

| 文件 | 具体作用 | 详情 |
|---|---|---|
| [analyze_read_scores.py](<analyze_read_scores.py>) | 在所属实验数据上计算/复核阅读、评分，输出派生统计或诊断；若用于选策略，应检查题目隔离与未来信息边界。 | [F0339](<../../../../../../docs/files/F0339.md>) |
| [audit_final.py](<audit_final.py>) | 对审计执行完整性、协议、评分、成本或可复现性检查；可能生成派生报告，不应直接视为新实验结果。 | [F0340](<../../../../../../docs/files/F0340.md>) |
| [run.sh](<run.sh>) | 该实验族的命令分派入口，转交准备/生成/合并/分析/自测；运行前须查看同版本命令分支与默认值。 | [F0342](<../../../../../../docs/files/F0342.md>) |
| [score_hotpot_read_openrouter.py](<score_hotpot_read_openrouter.py>) | 执行该协议的评分、Hotpot、阅读阶段；涉及外部模型/检索或特征计算与否，见风险标记和具体入口。 | [F0343](<../../../../../../docs/files/F0343.md>) |
| [self_test.py](<self_test.py>) | 检查self_test.py相关协议、断言或回归；部分测试使用mock，是否会加载模型应查看依赖与风险标记。 | [F0344](<../../../../../../docs/files/F0344.md>) |
