# PUB001 · verify_repository.py

源码：[tools/verify_repository.py](../../tools/verify_repository.py)

## 具体作用

不导入历史代码、不联网、不执行推理，检查文件hash、每份代码的功能说明覆盖、Python语法、链接和不应上传的资产。

输入：仓库内catalog/files.json、源码、生成的说明文档。
输出：标准输出JSON及退出码；成功为0，异常为1，不修改实验文件。

```bash
python3 tools/verify_repository.py
```

这是本次新增的维护工具，不属于论文实验方法。静态检查通过不代表服务器实验已复现。
