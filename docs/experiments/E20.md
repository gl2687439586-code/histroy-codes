# E20 · Adaptive-k：E5排序间隙动态选文档数

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

复现检索排名间隙选k，冻结问题与检索根后生成答案，独立核对subEM/EM与输出格式。

## 输入与输出

- 输入：Hotpot500、Qwen3、E5文档得分及检索根。
- 输出：chosen-k、generations、subEM/EM/F1/成本与r1/r2审计。

## 主入口

- [experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/build_roots.py](<../../experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/build_roots.py>)：每题恰好一次带分数Top-N检索，根据Adaptive-k规则选择文档并冻结root；不是先让LLM生成首搜query。
- [experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/adaptive_k.py](<../../experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/adaptive_k.py>)：依据检索分数间隔选择保留文档数k；不是直接选择LLM总token预算。
- [experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/run_generation.py](<../../experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/run_generation.py>)：对选定检索文档生成答案，保留所选k、输出和成本。
- [experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/analyze.py](<../../experiments/E20/scripts/experiments/adaptive_k_hotpot500_qwen3_v1/analyze.py>)：在所属实验数据上计算/复核analyze.py，输出派生统计或诊断；若用于选策略，应检查题目隔离与未来信息边界。
