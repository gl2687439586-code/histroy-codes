# E10 · FanOutQA random100 Wiki2023 自然检索预算

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

使用 Wiki2023 Kiwix 检索与自然 up-to-5 返回，比较 Blank、各预算与事后 Oracle，计算 FanOut 指标。

## 输入与输出

- 输入：FanOutQA random100、Wiki2023/ZIM、Kiwix 服务、Qwen3、冻结根。
- 输出：1126 条预算轨迹、Blank、Loose/Strict/ROUGE、搜索与实际成本。
