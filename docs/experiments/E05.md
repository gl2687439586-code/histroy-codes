# E05 · Qwen3-only v6：Blank/Neutral/Search–Read–Commit 树

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

生成 Qwen3 Blank，自然/强制首搜根，展开 S/R/C 树，对齐 neutral prompt；统计质量、真实成本、Oracle/Pareto。

## 输入与输出

- 输入：Bamboogle 样本；Qwen3 模型端点；Top-5 Retriever；根和三条件配置。
- 输出：01_blank、roots、02_src_tree、03_neutral、joint_analysis。

## 主入口

- [experiments/E05/scripts/experiments/src_action_tree/run_qwen3_three_conditions.sh](<../../experiments/E05/scripts/experiments/src_action_tree/run_qwen3_three_conditions.sh>)：执行该协议的条件阶段；涉及外部模型/检索或特征计算与否，见风险标记和具体入口。
- [experiments/E05/scripts/experiments/src_action_tree/run_qwen3_natural.py](<../../experiments/E05/scripts/experiments/src_action_tree/run_qwen3_natural.py>)：生成Qwen3-only Blank/Neutral自然搜索轨迹，并记录条件和成本。
- [experiments/E05/scripts/experiments/src_action_tree/prepare_qwen3_roots.py](<../../experiments/E05/scripts/experiments/src_action_tree/prepare_qwen3_roots.py>)：导出Qwen自然首搜根，必要时生成强制首搜根，并记录来源。
- [experiments/E05/scripts/experiments/src_action_tree/run_action_tree.py](<../../experiments/E05/scripts/experiments/src_action_tree/run_action_tree.py>)：从同一checkpoint递归展开Search/Read/Commit，执行动作约束并保存终止轨迹。
- [experiments/E05/scripts/experiments/src_action_tree/analyze_qwen3_conditions.py](<../../experiments/E05/scripts/experiments/src_action_tree/analyze_qwen3_conditions.py>)：比较Blank、Neutral与SRC树，区分自然根/强制根并汇总质量成本。
