# E09 · HotpotQA random500 v4.3.3 自然搜索主线

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

Top-5 完整拼接、100-token 全局前缀与 FULL；模型自然搜索至多 4 次，产生最初 500 题预算轨迹。

## 输入与输出

- 输入：冻结的 random500 ID、Qwen3、Retriever、每题根证据长度决定的档位。
- 输出：roots、trajectories、scored_records、每预算质量/成本/Oracle。

- [experiments/E09/scripts/experiments/hotpot_concat100_random500_v4/tmux_2gpu.sh](<../../experiments/E09/scripts/experiments/hotpot_concat100_random500_v4/tmux_2gpu.sh>)：将该目录的服务、worker或协调器放入tmux，提供运行/状态/日志入口；可能启动GPU任务或结束特定会话。
