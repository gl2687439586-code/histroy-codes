# E12 · HotpotQA/FanOutQA 原问题 READ/SEARCH 评分

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

通过同类评分prompt给原始问题标注证据需求，保存结构化分数、置信度、请求、usage与恢复日志。

## 输入与输出

- 输入：原问题列表、OpenRouter GPT-5.6-Sol 配置、API key。
- 输出：read_scores/query_scores、评分分布、usage、validation_report。
