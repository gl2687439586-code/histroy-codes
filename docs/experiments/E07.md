# E07 · Top-5 单轮 B50–750 Answer-only 暴露

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

固定 root 的 Top-5 文档，按 150-token 文档槽位逐步暴露，每个题目×预算只调用一次答案模型，本地计算 EM/F1。

## 输入与输出

- 输入：Bamboogle root_cache.jsonl、Qwen3 tokenizer/端点；B50–750 配置。
- 输出：records.jsonl、failures、75/1875 条记录、预算质量成本表与审计。

- [experiments/E07/scripts/experiments/blank_answer_only/run.sh](<../../experiments/E07/scripts/experiments/blank_answer_only/run.sh>)：该实验族的命令分派入口，转交准备/生成/合并/分析/自测；运行前须查看同版本命令分支与默认值。
