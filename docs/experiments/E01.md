# E01 · SmartSearch 原模型的 Bamboogle 复现

状态：部分定位／精确结果行未绑定

## 目的

保留本地上游推理、评估、检索服务源码作为早期复现的框架依赖；不把它冒充当时修改后的服务器快照。

## 输入与输出

- 输入：Bamboogle、SmartSearch-3B、Wikipedia 语料及索引、当时的推理配置。
- 输出：原始 intermediate_data、逐题答案、EM/F1。

## 主入口

- [third_party/SmartSearch/scripts/inference/re_call_use_case.py](<../../third_party/SmartSearch/scripts/inference/re_call_use_case.py>)：ReCall使用示例：配置模型与工具并发起推理；不是历史批量实验锁定配置。
- [third_party/SmartSearch/src/re_call/__init__.py](<../../third_party/SmartSearch/src/re_call/__init__.py>)：Python包初始化与导出定义，供同目录模块导入。
- [third_party/SmartSearch/src/re_call/inference/__init__.py](<../../third_party/SmartSearch/src/re_call/inference/__init__.py>)：Python包初始化与导出定义，供同目录模块导入。
- [third_party/SmartSearch/src/re_call/inference/re_call.py](<../../third_party/SmartSearch/src/re_call/inference/re_call.py>)：原始ReCall智能体循环：模型生成、工具动作解析/执行、Observation回填及终止。
- [third_party/SmartSearch/src/re_call/inference/serper_test.py](<../../third_party/SmartSearch/src/re_call/inference/serper_test.py>)：Serper网络搜索接口测试；不是实验采用的Wikipedia dense检索主入口。
