# E24 · 证据截断/支持句可见性与答案翻转

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

在全量相邻预算对中联合检查答案翻转与完整可见支持句的新增/丢失，并核对前缀/重复暴露。

## 输入与输出

- 输入：全量评分、supporting evidence位置/可见性、同题预算配对。
- 输出：evidence_window_audit、支持句新增/丢失×正确性翻转计数。

## 主入口

- [analysis/outputs/hotpot_deep_recheck_20261003/audit_evidence_windows.py](<../../analysis/outputs/hotpot_deep_recheck_20261003/audit_evidence_windows.py>)：联合审计相邻预算答案翻转与完整可见支持句的新增/丢失。
- [analysis/outputs/hotpot_deep_recheck_20261003/audit_balanced_prefix.py](<../../analysis/outputs/hotpot_deep_recheck_20261003/audit_balanced_prefix.py>)：对审计执行完整性、协议、评分、成本或可复现性检查；可能生成派生报告，不应直接视为新实验结果。
- [analysis/outputs/hotpot_deep_recheck_20261003/audit_repeat_exposure.py](<../../analysis/outputs/hotpot_deep_recheck_20261003/audit_repeat_exposure.py>)：对审计、重复执行执行完整性、协议、评分、成本或可复现性检查；可能生成派生报告，不应直接视为新实验结果。
