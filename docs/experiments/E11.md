# E11 · 语义答案复核与 EM+Semantic 指标

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

对存储答案构建去重盲评队列、录入人工/Codex语义标签，合并EM与复核标签，检查Oracle空间。

## 输入与输出

- 输入：原答案/gold、EM 分数、人工语义标签及队列哈希。
- 输出：label ledger、语义质量/成本表、预算区间、可复核标签清单。

## 主入口

- [analysis/analysis_token_ranges_20261010/combine_em_semantic.py](<../../analysis/analysis_token_ranges_20261010/combine_em_semantic.py>)：合并EM正例与明确语义复核标签；未复核的非EM答案保留未知，不推断为错误。
- [analysis/analysis_token_ranges_20261010/full_semantic_review.py](<../../analysis/analysis_token_ranges_20261010/full_semantic_review.py>)：建立盲语义复核队列并管理人工标签；本工具不自动预测标签。
- [analysis/analysis_token_ranges_20261010/finalize_full_semantic_review.py](<../../analysis/analysis_token_ranges_20261010/finalize_full_semantic_review.py>)：合并语义复核标签并生成最终覆盖/质量/成本汇总。
- [analysis/analysis_token_ranges_20261010/verify_semantic_export.py](<../../analysis/analysis_token_ranges_20261010/verify_semantic_export.py>)：只读核验语义导出包hash、标签覆盖和汇总重算是否一致。
