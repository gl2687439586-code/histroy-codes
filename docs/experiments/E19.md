# E19 · TALE-EP：预算估计与受预算提示推理

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

先估计推理预算，再用预算prompt在自然搜索框架中推理，分开记录估计器和执行器成本。

## 输入与输出

- 输入：冻结的498/500题ID、预算估计结果、Qwen端点、Retriever。
- 输出：estimates、trajectories、计费完整性与质量成本。
