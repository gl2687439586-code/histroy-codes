# E13 · FanOutQA READ 同分组留一预算分配

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

对齐评分和预算轨迹，留出当前题，在其他同分题中学习预算并评估；另计算需求/Oracle关联与成本。

## 输入与输出

- 输入：100题评分、1126轨迹、Blank、FanOut标签。
- 输出：loo_read_score_group、policy_comparison、关联审计与论文分配示意图。
