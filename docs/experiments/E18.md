# E18 · Plan-and-Budget：Cosine/Polynomial 迁移

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

规划子问题与难度，用Cosine/Polynomial分配预算，再检索并回答；独立审计两种调度。

## 输入与输出

- 输入：Hotpot500、planner与solver模型配置、规划结果、检索服务。
- 输出：plans、Cosine/Polynomial轨迹、预算使用与质量成本对照。

## 主入口

- [experiments/E18/scripts/experiments/plan_and_budget_hotpot_agent_v2_soft/plan_questions.py](<../../experiments/E18/scripts/experiments/plan_and_budget_hotpot_agent_v2_soft/plan_questions.py>)：调用规划器分解子问题并估计难度，为Plan-and-Budget提供调度输入。
- [experiments/E18/scripts/experiments/plan_and_budget_hotpot_agent_v2_soft/run_trajectories.py](<../../experiments/E18/scripts/experiments/plan_and_budget_hotpot_agent_v2_soft/run_trajectories.py>)：从冻结root按本实验预算协议续写，执行检索循环，保存完整episode与失败/成本。
- [experiments/E18/scripts/experiments/plan_and_budget_hotpot_agent_v2_soft/analyze.py](<../../experiments/E18/scripts/experiments/plan_and_budget_hotpot_agent_v2_soft/analyze.py>)：在所属实验数据上计算/复核analyze.py，输出派生统计或诊断；若用于选策略，应检查题目隔离与未来信息边界。
- [analysis/pandb_hotpot500_dual_qwen_coordinator.sh](<../../analysis/pandb_hotpot500_dual_qwen_coordinator.sh>)：协调双Qwen的Plan-and-Budget500题运行阶段和日志；模型组合有别于原规划器配置。
