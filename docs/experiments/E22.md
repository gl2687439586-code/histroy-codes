# E22 · HotpotQA 全量7405 v4.3.3及答案翻转

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

冻结全量7405题，GPU2/3自然搜索预算实验；合并核验与EM/F1/ACC/成本/Oracle/MSB/SSB/翻转统计。

## 输入与输出

- 输入：Hotpot dev7405、Qwen3、E5 Retriever、context/token-pool配置。
- 输出：7405 roots、61754轨迹、完整性manifest、全量统计/Pareto。
