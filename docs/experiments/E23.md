# E23 · 匹配500题五次执行：成功集合与特权迁移

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

在原两轮之上新执行三轮，重建每轮root；对齐五轮raw上下文、预算集合、稳定性与同题历史标签策略。

## 输入与输出

- 输入：原500与全量中对应500的raw包、新三轮review包、同一500题ID。
- 输出：五轮质量成本、Oracle、共同成功预算、迁移策略、raw审计。
