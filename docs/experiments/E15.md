# E15 · HotpotQA↔FanOutQA 跨数据集评分迁移

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

源数据学评分—预算映射，目标数据评估；比较绝对映射、分位数校准、指标对齐、软策略。

## 输入与输出

- 输入：Hotpot500和FanOut100的评分及公共B100–600轨迹。
- 输出：policy_summary、harmonized/quantile表、置信区间与迁移图。
