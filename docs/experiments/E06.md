# E06 · GPT-5.6/OpenRouter：Blank/Neutral/SRC 对照

状态：已定位相关实现；未证明与远程运行字节级一致

## 目的

将三条件工作流接入 OpenRouter，保留 prompt、请求、usage 与计费，比较直接回答/中性续写/树。

## 输入与输出

- 输入：Bamboogle、OpenRouter 模型配置和用户自行提供的 API key、检索端点。
- 输出：三条件轨迹、协议审计、token/计费汇总。

## 主入口

- [experiments/E06/scripts/experiments/src_action_tree/run_openrouter_three_conditions.sh](<../../experiments/E06/scripts/experiments/src_action_tree/run_openrouter_three_conditions.sh>)：执行该协议的条件阶段；涉及外部模型/检索或特征计算与否，见风险标记和具体入口。
- [experiments/E06/scripts/experiments/src_action_tree/run_openrouter_natural.py](<../../experiments/E06/scripts/experiments/src_action_tree/run_openrouter_natural.py>)：经OpenRouter调用历史API模型，生成Blank/Neutral自然轨迹并保存响应与usage。
- [experiments/E06/scripts/experiments/src_action_tree/prepare_openrouter_roots.py](<../../experiments/E06/scripts/experiments/src_action_tree/prepare_openrouter_roots.py>)：为OpenRouter模型准备自身首Search状态，避免混用其他模型的root。
- [experiments/E06/scripts/experiments/src_action_tree/analyze_openrouter_conditions.py](<../../experiments/E06/scripts/experiments/src_action_tree/analyze_openrouter_conditions.py>)：在所属实验数据上计算/复核条件，输出派生统计或诊断；若用于选策略，应检查题目隔离与未来信息边界。
- [experiments/E06/scripts/experiments/src_action_tree/summarize_openrouter_billing.py](<../../experiments/E06/scripts/experiments/src_action_tree/summarize_openrouter_billing.py>)：整理所属实验的summarize_openrouter_billing.py统计与报告；结果有效性取决于输入记录与评分口径。
